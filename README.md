# Vanishka Enterprises — Official Website

Modern, responsive website for **Vanishka Enterprises** (Nagpur, Maharashtra), specializing in computer, laptop, and IT hardware repair, networking, sales, and support services.

---

## 📁 Project Structure

```text
vanshikaentreprice/
├── index.html        # Main Landing Page (Hero Slider, Instant Quote Engine, Symptom Checker, Services, Rates)
├── about-us.html     # About Us Page (Company story, technical capabilities, values)
├── contact.html      # Contact & Booking Page (Doorstep repair inquiry form, live Google Maps embed)
├── images/           # Brand logos, 3D hardware graphics, product photos, banners
└── README.md         # Project documentation & overview
```

---

## 🚀 Key Features

1. **Homepage (`index.html`)**:
   - Modern glassmorphism sticky navigation bar with WhatsApp & Call CTAs.
   - Interactive Hero hardware section with dynamic slider and 3D spatial cards.
   - **Instant Quote Engine**: Real-time diagnostic and repair pricing estimator.
   - **AI Symptom Checker**: Interactive troubleshooter for laptops and PCs.
   - **Transparent Nagpur Rates**: 6-card service showcase with quick dispatch actions.
   - Chip-level BGA motherboard repair highlight banner.
   - Floating WhatsApp quick-connect button.

2. **About Us (`about-us.html`)**:
   - 10+ years industry experience showcase (Est. 2013).
   - Workshop capabilities (cleanroom data recovery, BGA rework stations).
   - Nagpur service location details.

3. **Contact (`contact.html`)**:
   - Online appointment & doorstep repair inquiry form.
   - Direct contact info for Chief Engineer Prabhu (+91 8600572488 / 7875165423).
   - Live interactive Google Maps embed for Nara Road, Jaripatka, Nagpur.

---

## 💻 Tech Stack

- **HTML5 & Vanilla JavaScript**: Clean, fast, zero build configuration needed.
- **Tailwind CSS (CDN)**: Modern utility-first responsive styling.
- **Google Fonts**: Inter & Poppins.
- **Assets**: Optimized PNG & WebP images in `images/`.

## 🌐 How to Preview Locally

Double-click `index.html` or open any of the HTML files in your web browser. You can also run a local server:

```bash
# Python
python -m http.server 8000

# or Node.js / npx
npx serve .
```
